# ZovPaint — Простой графический редактор

## Возможности

- ✅ Рисование кистью с антиалиасингом (сглаживание)
- ✅ Два цвета: основной (Левая кнопка мыши) и дополнительный (Правая кнопка мыши)
- ✅ Регулируемый размер кисти от 1 до 30
- ✅ Очистка холста
- ✅ Сохранение рисунка в **PNG** и **JPG**
- ✅ Удобное русскоязычное меню
- ✅ Цветовая панель в верхней части окна
- ✅ Высокое качество отрисовки

### Основные компоненты кода:

- **penisSize** — размер кисти (название оставлено как в оригинале)
- **primaryColor** — цвет для ЛКМ
- **secondaryColor** — цвет для ПКМ
- **canvas** — Bitmap, на котором происходит рисование
- Обработка событий мыши (`MouseDown`, `MouseMove`, `MouseUp`)
- `MenuStrip` с меню: **Файл**, **Правка**, **Инструменты**

---

## Как запустить проект

1. Открой проект в **Visual Studio** (рекомендуется 2022)
2. Убедись, что целевая платформа — **.NET Framework 4.7.2** или выше
3. Замени содержимое `Form1.cs` на код из проекта
4. Нажми `F5` для запуска

---

## Как использовать

- **ЛКМ** — рисовать основным цветом
- **ПКМ** — рисовать вторым цветом
- **Инструменты → Размер кисти** — изменить толщину
- **Инструменты → Выбрать основной/второй цвет** — выбор цвета
- **Правка → Очистить холст** — очистить рисунок
- **Файл → Сохранить как...** — сохранить изображение
